# Changelog

## [0.1] — First release

### Added

- Native Apple Silicon app with Dark, Medium and Light themes.
- DSO2D15 two-channel capture and instrument controls.
- Measurements, FFT, cursors and reference traces.
- Snapshot recording, offline playback, trends and bookmarks.
- PNG/CSV export and offline demo mode.
- DMG/ZIP packages, PHP website and GitHub/GitLab release tooling.
